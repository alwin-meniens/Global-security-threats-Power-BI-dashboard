# CyberRisk Intelligence | Power BI Dashboard

[![Power BI](https://img.shields.io/badge/Power_BI-Desktop-F2C811?logo=powerbi&logoColor=black)](https://powerbi.microsoft.com/)
[![Dataset: Kaggle](https://img.shields.io/badge/Dataset-Kaggle-20BEFF?logo=kaggle&logoColor=white)](https://www.kaggle.com/datasets/atharvasoundankar/global-cybersecurity-threats)
[![License: CC0-1.0](https://img.shields.io/badge/License-CC0_1.0-lightgrey.svg)](http://creativecommons.org/publicdomain/zero/1.0/)

This project is a Power BI dashboard that explores cybersecurity incidents, financial losses, attack patterns, and response times across countries and industries. It was built as an educational business intelligence project to analyse trends in a structured cyber incident dataset.

- Microsoft Power BI Desktop

## Dashboard Features
- KPI cards for total incidents, total financial impact, and average response time
- Financial loss trends across 2015–2024
- Country-level comparison of cumulative financial impact
- Industry-level comparison of reported losses
- Attack-type distribution across major cyber threat categories
- Interactive filtering for dashboard exploration

## Data Source
- [Global Cybersecurity Threats (2015–2024)](https://www.kaggle.com/datasets/atharvasoundankar/global-cybersecurity-threats)

## Data Limitation
This dashboard is based on a curated dataset of recorded incidents and has not been independently verified against real-world incident reports. The analysis is intended for learning and exploratory BI work, not for presenting independently verified global cybersecurity statistics.
